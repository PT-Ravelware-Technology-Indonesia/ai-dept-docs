## Project Overview

**Edge PPE Monitoring** (`edge-ppe-monitoring`) merupakan sistem pengawasan kepatuhan Alat Pelindung Diri (APD / *Personal Protective Equipment*) berbasis computer vision yang dideploy secara *on-premises* pada perangkat edge (mini PC). Sistem ini mendukung integrasi hingga 4 IP Camera melalui RTSP stream, live streaming berlatensi rendah via WebRTC dan HLS, inferensi AI terjadwal dengan model YOLO, notifikasi real-time via WebSocket, dan pencatatan log deteksi visual dengan frame beranotasi.

Seluruh sistem dirancang *self-contained* menggunakan Docker Compose tanpa ketergantungan cloud, menjaga seluruh data video dan analitik tetap berada di dalam jaringan lokal (LAN).

---

## Konteks Bisnis

Di industri manufaktur, pergudangan, dan konstruksi, kepatuhan penggunaan APD (helm keselamatan, rompi, sepatu safety, masker) adalah syarat mutlak Keselamatan dan Kesehatan Kerja (K3). Pengawasan manual seringkali tidak efektif karena area kerja yang luas dan keterbatasan personel K3.

Edge PPE Monitoring hadir untuk:
1. **Otomatisasi Pengawasan K3**: Mendeteksi pelanggaran atau kepatuhan APD secara real-time dan terjadwal.
2. **Privasi & Keamanan Data (Zero Cloud)**: Seluruh pemrosesan stream video, inferensi AI, dan penyimpanan riwayat dilakukan lokal di edge device, menjaga privasi data pabrik.
3. **Efisiensi Perangkat Keras**: Dioptimalkan untuk berjalan pada mini PC kelas menengah (misalnya Intel NUC, i3+, RAM 8GB) menggunakan inferensi CPU (PyTorch CPU / OpenVINO) tanpa memerlukan GPU workstation yang mahal.
4. **Fleksibilitas Operasional**: Jadwal inferensi dapat dikustomisasi per kamera menggunakan ekspresi cron (misalnya hanya aktif pada jam kerja tertentu).

## Komponen Utama

| Komponen | Lokasi File | Tanggung Jawab |
| --- | --- | --- |
| **FastAPI Core & Router** | `app/main.py`, `app/router/` | Endpoint REST API (CRUD kamera, riwayat deteksi, model AI, demo stream) dan WebSocket gateway. |
| **Camera Service** | `app/services/camera_service.py` | Validasi RTSP, konfigurasi IP lokal, integrasi path ke MediaMTX API. |
| **MediaMTX Service** | `app/services/mediamtx_service.py` | Manajemen dinamis path streaming RTSP/WebRTC/HLS pada server MediaMTX secara runtime tanpa restart. |
| **Frame Capture Service** | `app/services/frame_capture_service.py` | Akuisisi frame dari RTSP stream dengan fallback retry logic saat koneksi drop. |
| **YOLO Service** | `app/services/yolo_service.py` | Wrapper Ultralytics YOLO dengan in-memory model caching, NMS tuning (conf & IoU), dan class filtering. |
| **Inference Task & Beat** | `app/tasks/inference_task.py`, `app/celery_app.py` | Eksekusi background task terjadwal untuk frame capture, inferensi AI, dan penyimpanan data. |
| **Inference Scheduler** | `app/services/inference_scheduler_service.py` | Evaluasi ekspresi cron dan validasi zona waktu aktif per kamera. |
| **Notification Service** | `app/services/notification_service.py` | Formatting template notifikasi dinamis dan broadcast pesan via WebSocket. |
| **Database Models** | `app/models/database.py` | Definisi SQLModel untuk entitas `Camera`, `InferenceResult`, `Detection`, dan `User`. |
| **Frontend UI** | `frontend/src/` | SPA React 19 dengan multi-view kamera, video player WebRTC/HLS, dashboard statistik, dan log viewer. |

## Fitur Utama

### 1. Manajemen Multi-Kamera
- Mendukung hingga 4 kamera IP aktif secara simultan dengan validasi subnet IP lokal (192.168.x.x, 10.x.x.x, 172.16-31.x.x).
- Fitur *dummy stream* / file video demo lokal untuk kemudahan demonstrasi tanpa kamera fisik.
- Pengaturan dinamis path MediaMTX via REST API tanpa perlu me-restart service streaming.

### 2. Penjadwalan Inferensi Fleksibel (Timezone-Aware)
- Jadwal deteksi dikonfigurasi per kamera menggunakan ekspresi cron (misalnya `* 8-17 * * 1-5` untuk hari kerja).
- Evaluasi jadwal berbasis zona waktu lokal kamera (misalnya `Asia/Jakarta`).

### 3. Model AI & Parameter Tuning
- Mendukung pemuatan model YOLO (`.pt`) secara dinamis dari folder `ai_models/`.
- Ambang batas deteksi (*confidence threshold*) dan IoU threshold dapat diatur per kamera.
- Pemilihan kelas spesifik (misal: person, helmet, vest) untuk menyaring objek yang tidak relevan.

### 4. Live Streaming & Notifikasi Real-time
- Streaming latensi rendah menggunakan WebRTC dengan fallback HLS melalui MediaMTX.
- Notifikasi deteksi instan disalurkan via WebSocket langsung ke antarmuka pengguna dengan format teks yang dapat dikustomisasi (*template tokens*: `[Class]`, `[Camera Name]`, `[Time]`).

### 5. Detection Logs & Visual Audit
- Setiap deteksi menyimpan snapshot gambar mentah dan gambar teranotasi (bounding box & confidence).
- Metadata koordinat box, kelas, dan waktu eksekusi tersimpan rapi di PostgreSQL untuk audit berkala.

## Deployment & Konfigurasi Edge

Sistem dijalankan pada edge device menggunakan Docker Compose:

```bash
# Clone repository
git clone https://github.com/PT-Ravelware-Technology-Indonesia/edge-ppe-monitoring.git
cd edge-ppe-monitoring

# Setup environment
cp .env.example .env

# Jalankan seluruh stack (Postgres, Redis, MediaMTX, FastAPI, Celery Worker, Celery Beat)
docker compose -f docker-compose.prod.yml up --build -d
```

Dashboard monitoring dapat langsung diakses melalui browser pada port `8000` (`http://<ip-edge-device>:8000`).
